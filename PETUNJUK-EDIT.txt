AKSI BUPATI CILIK PEDULI LINGKUNGAN - VERSI YANG BISA DIEDIT
=============================================================

CARA MEMAINKAN
1. Ekstrak (Extract All) seluruh isi ZIP ke satu folder. Jangan buka index.html dari dalam ZIP.
2. Klik dua kali index.html (disarankan Chrome atau Edge). Tidak perlu internet.
3. Jangan memindahkan index.html keluar dari folder ini, karena gambar dan musik dibaca dari folder css/ dan assets/.

ISI FOLDER
  index.html            -> kode game (HTML + gaya + JavaScript). Edit dengan Notepad / VS Code.
  css/                  -> gaya hasil kompilasi (tailwind.css, fontawesome.css). Jangan diedit.
  assets/images/        -> gambar latar, peta, dan lain-lain
  assets/char/          -> 6 gambar karakter (laki / perempuan: idle, interaction, celebrate)
  assets/audio/         -> musik latar (musik-latar.mp3)
  assets/fonts/         -> huruf & ikon
  naskah/               -> daftar teks narasi (naskah-narasi.csv), hanya sebagai dokumentasi
  cek-voice.html        -> halaman pemeriksa voice perangkat (untuk pengembang)

MENGEDIT TEKS (cari dengan Ctrl+F di Notepad)
  - Dialog Bupati Cilik Janji   : cari  "Selamat atas pelantikanmu"
  - Dialog Peta                 : cari  "Selamat datang di Peta"
  - Teks pembuka (4 narasi)     : cari  NARRATIVE_STEPS
  - Petunjuk tiap zona          : cari  desc.innerText
  - Soal Zona 4 dan Zona 5      : cari  zone4Questions dan schoolQuestions
  - Ucapan selesai misi         : cari  PRAISE

NARASI SUARA (Web Speech API bawaan peramban)
  - Narasi dibacakan langsung oleh peramban (speechSynthesis). Tidak ada file MP3 narasi, API key, atau Python.
  - Teks yang dibacakan ada di index.html, objek Voice -> TEXT (id: teks). Ubah teksnya di sana bila perlu.
  - Karakter laki-laki memakai voice laki-laki Indonesia, perempuan memakai voice perempuan Indonesia - JIKA perangkat punya.
    Bila tidak ada, dipakai voice Indonesia yang tersedia dan game menampilkan pemberitahuan.
  - Tombol 🗣️ (kanan bawah) = narasi aktif/mati. Tombol 🔁 = ulangi narasi. Tombol 🎚️ = volume + Periksa Voice Perangkat.
  - Periksa voice: buka cek-voice.html atau 🎚️ -> "Periksa voice perangkat".

SIMPAN FILE dengan encoding UTF-8 agar huruf dan emoji tidak rusak.
Sebelum mengedit, salin dulu folder ini sebagai cadangan.

PAPAN SKOR & SERTIFIKAT
  - Tombol 🏆 (kanan bawah) membuka Papan Skor: nama, asal sekolah, kelas, nilai tiap zona, total. Dapat diunduh sebagai CSV (Excel).
  - Data papan skor tersimpan di peramban perangkat yang dipakai bermain (tidak ada server). Menghapus data situs/riwayat peramban menghapus papan skor.
  - Tanggal & jam di sertifikat otomatis sesuai waktu perangkat saat murid menyelesaikan semua zona.
